# DSA-Codes

A personal repository of Data Structures and Algorithms implementations in **C** and **C++**, built while following the [Love Babbar / CodeHelp DSA roadmap](https://www.youtube.com/@CodeHelp).

---

## Topics Covered

- **Arrays** — 1D/2D operations, rotation, spiral print, staircase search
- **Sorting Algorithms** — Bubble, Selection, Insertion, Merge Sort (with complexity analysis)
- **Linked Lists** — Singly, Doubly, Circular (in C)
- **Stacks** — Array and linked list based implementations
- **Strings** — Manipulation and pattern problems
- **Pointers & Memory** — Dynamic allocation, pointer arithmetic
- **Bitwise Operators** — Bit manipulation techniques
- **Mathematics in DSA** — Number theory, modular arithmetic
- **LeetCode Questions** — Practice problems with solutions
